## 3. Improvement suggestions

### A. Zenith website & trust
1. **Fix hero metrics** — Stats currently render as `0+` / `0%`. Replace with real numbers or remove until live. Broken trust metrics hurt conversion more than missing ones.
2. **Surface in-house AI** — Add a “Products” row for **Colour Analysis AI** and **Zenith Fashion / J.E.R.K.** with: problem → model approach → demo CTA.
3. **Proof blocks** — Short case snippets (before/after, latency, accuracy, user save-rate) beat generic “enterprise AI” copy.

### B. J.E.R.K. product & Colour Analysis AI
1. **Make Colour Analysis the hero loop**  
   Flow: selfie upload → undertone/season → 6–8 hex palette → 2–3 outfit recommendations.  
   This is the most Instagram-native AI demo in the stack.
2. **Show method, not only claims** — For “100K+ users / 10M+ data points”, add source categories, refresh time, and confidence score on Trendwall cards.
3. **India-context styling** — Extend recommendations for office / festive / wedding / campus occasions and Indian wardrobe constraints (dupatta, kurtas, layering weather).
4. **Feedback loop for model quality** — Track save / wear / reject on looks → improve ranking. Publish a simple “match quality improved X%” metric over time.
